# 3D Platformer Game

A 3D platformer game built with Three.js

## Features
- 3D platformer gameplay
- Player movement and jumping mechanics
- Multiple platforms to navigate
- Smooth camera following
- Shadow and lighting effects

## Controls
- **WASD** - Move the player
- **SPACE** - Jump

## How to Play
1. Open `index.html` in a web browser
2. Use WASD keys to move around
3. Press SPACE to jump
4. Navigate across the platforms to explore the world
5. Try not to fall off!
